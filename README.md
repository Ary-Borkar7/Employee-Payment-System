   # Employee Payment System
   
   Java AWT Applet that calculates Gross Salary and Net Salary for employees based on their designation.
   
   **Features:**
   - Calculates DA (40%), HRA (10%), MA (5%), CA (5%) from Basic Salary
   - Computes Gross Salary and 18% Deduction for Net Salary
   - Role-based calculation: Tester, Manager, Developer
   - GUI built with Java AWT using Labels, TextFields, Buttons
   
   **Tech Used:** Core Java, Java AWT, Event Handling, OOP
   
   **How to Run:**
   1. Compile: `javac Employee.java`
   2. Run: `appletviewer Employee.java`
